새로운 파일럿을 방제단에 초대하려면 어떻게 하나요?

파일럿분들은 새로운 방제단원을 초대할 수 없습니다. 방제단장이 본인의 계정으로 로그인하면 화면 상단에 초대 코드가 보입니다. 누르면 코드를 복사할 수 있고, 복사하신 코드를 새로 함께할 파일럿에게 전달해 회원가입을 진행할 때 입력하도록 안내해 주세요.

내 작업 지도에서 GPS 연결은 어떻게 해야 하나요?

[내 할당 필지] 화면에서 내 작업지도 왼쪽 위에 위치해 있는 입력란에 조종사명을 입력하고 [실제 GPS 시작] 버튼을 눌러주세요. 지도위에 위치가 잘 뜨는지 확인후 작업을 시작해 주시면 됩니다. [중지] 버튼을 누르시면 위치 전송이 중지됩니다.

드론이나 약제는 어떻게 등록하나요?

드론 · 약제 페이지에 들어가 화면 상단에 [+ 자산 등록] 버튼을 누른 뒤 올바른 내용을 기입하고 [등록] 버튼을 누르시면 새로운 드론 혹은 약제가 추가됩니다.

작업은 어떻게 배정받나요?

방제단장이 농지를 선택해 조종사에게 배정합니다. 조종사는 [내 할당 필지]와 [작업 관리] 화면에서 배정받은 작업을 확인할 수 있습니다.

작업은 어떻게 시작하고 완료하나요?

작업 관리 화면에서 대기 중인 작업을 선택하고, 사용할 드론과 약제를 고른 뒤 [작업 시작]을 누르세요. 방제가 끝나면 [작업 완료 보고]를 누르면 됩니다.

조종사도 농지를 등록할 수 있나요?

농지 등록은 방제단장만 할 수 있습니다. 조종사는 배정받은 농지에서만 작업을 진행할 수 있습니다.

고압선 같은 위험한 곳을 발견했어요.

게시판의 위험 구역 탭에서 [+ 위험 구역 신고]를 눌러 정확한 위치와 내용을 등록해 주세요. 사진을 함께 첨부해 주시면 어떤 상황이 발생중인지 파악하는데 많은 도움이 됩니다. 등록된 게시글은 모든 방제단이 함께 확인할 수 있어 사고 예방에 도움이 됩니다.

연락처나 비밀번호를 변경하고 싶어요.

화면 우측 상단에 표시된 [본인의 이름]을 클릭하면 마이페이지로 이동할 수 있습니다. 마이페이지에서 연락처 혹은 비밀번호를 변경해 주세요.

시스템 사용 중 오류가 발생했어요.

잠시 후 다시 시도해 주세요. 같은 오류가 계속 발생하면 오른쪽 [1:1 문의하기]로 남겨 주세요. 확인 후 답변드리겠습니다.
