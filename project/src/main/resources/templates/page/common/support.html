❓ 자주 묻는 질문

새로운 조종사를 방제단에 초대하려면 어떻게 하나요?

조종사 초대는 방제단장만 할 수 있습니다. 방제단장 계정으로 로그인하면 화면 상단에 초대 코드가 표시되며, 코드를 클릭하면 복사됩니다. 복사한 코드를 초대할 조종사에게 전달하여 회원가입 시 입력하도록 안내해 주세요.

GPS 위치 전송은 어떻게 시작하나요?

[내 할당 필지]의 작업 지도에서 [실제 GPS 시작]을 누르면 위치 전송이 시작됩니다. 현재 위치가 지도에 정상 표시되면 작업을 진행하세요. [일시정지]는 작업을 잠시 멈추고, [중지]는 위치 전송을 종료합니다.

드론과 약제는 어떻게 등록하나요?

[드론 · 약제] 메뉴 상단의 [+ 자산 등록]을 선택한 후 항목별 정보를 입력하고 [등록]을 누르시면 신규 드론 또는 약제가 목록에 추가됩니다.

작업 배정은 어떻게 이루어지나요?

작업 배정은 방제단장이 농지를 선택하여 담당 조종사에게 지정하는 방식으로 진행됩니다. 배정이 완료되면 [내 할당 필지] 및 [작업 관리] 화면에서 배정 내역을 확인하실 수 있습니다.

작업 시작과 완료 보고는 어떻게 하나요?

[작업 관리] 화면에서 대기 중인 작업을 선택하고, 사용할 드론과 약제를 지정한 후 [작업 시작]을 눌러 주세요. 방제 작업이 끝나면 [작업 완료 보고]를 선택하여 작업을 종료하실 수 있습니다.

조종사도 농지를 등록할 수 있나요?

농지 등록은 방제단장 권한으로만 가능합니다. 조종사는 방제단장이 배정한 농지에 한하여 작업을 수행하실 수 있습니다.

고압선 같은 위험한 곳을 발견했어요.

[게시판]의 [위험 구역] 탭에서 [+ 위험 구역 신고]를 선택한 후 위치와 상세 내용을 등록해 주세요. 현장 사진을 함께 첨부하시면 위험 상황을 보다 정확하게 공유할 수 있습니다. 등록된 신고는 모든 방제단에 공개되며, 위험이 해소된 경우 작성자 본인, 방제단장 또는 관리자가 [해소 완료]로 변경할 수 있습니다.

연락처나 비밀번호를 변경하고 싶어요.

화면 우측 상단의 사용자 이름을 선택하면 마이페이지로 이동합니다. 마이페이지에서 연락처와 비밀번호를 변경하실 수 있습니다.

시스템 사용 중 오류가 발생했어요.

일시적인 오류일 수 있으니 잠시 후 다시 시도해 주세요. 동일한 문제가 반복되는 경우 화면 오른쪽의 [1:1 문의하기]로 접수해 주시면 확인 후 답변드리겠습니다.

검색 결과가 없습니다. 오른쪽 [1:1 문의하기]로 질문해 주세요.
