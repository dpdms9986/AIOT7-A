이용 안내

이용 안내

서비스 이용 방법을 단계별로 확인해 보세요.

1

회원가입 및 방제단 생성

계정을 만들고 방제단 이름을 입력합니다.

2

초대 코드 공유

가입 후 확인되는 초대 코드를 조종사에게 전달합니다.

3

농지 등록

지도에서 농지를 찾아 면적과 정보를 입력합니다.

4

조종사에게 작업 배정

농지를 영역별로 묶어 조종사에게 배정하고 진행 상황을 확인합니다.

1

회원가입 및 초대 코드 입력

드론 조종사로 가입하고 방제단장에게 받은 초대 코드를 입력합니다.

2

할당 농지 확인

로그인 후 내 할당 필지에서 배정받은 농지를 확인합니다.

3

작업 시작

현장에 도착하면 작업 시작 버튼을 눌러 작업을 시작합니다.

4

작업 완료 보고

작업이 끝나면 완료 버튼을 눌러 방제단장에게 보고합니다.

🛡️

안전 게시판 이용

위험 요소나 특이사항을 사진과 함께 공유하고, 모두의 안전한 작업 환경을 만들어 보세요.
